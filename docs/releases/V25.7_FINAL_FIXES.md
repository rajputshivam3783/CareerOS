# CareerOS V25.7 Final Fixes

## Included
- Gemini native REST authentication uses `x-goog-api-key`.
- Gemini provider handles missing keys, HTTP errors, network errors, empty/blocked responses.
- Gemini is the default provider in `.env.example`.
- Career Copilot and Mock Interview continue to use the shared AI completion gateway.
- Government source verification is isolated per source.
- `scripts/run_all_government_sources.py` verifies disabled sources, optionally activates only sources returning records, then runs every active source independently.
- Admin endpoint `POST /government/sources/run-all?activate_verified=true` provides the same workflow from the admin panel/API.
- Existing government ingestion pipeline remains review-queue based; jobs are not auto-published.
- Generated caches, local databases, `.env`, node_modules, `.next`, virtualenvs and Python bytecode are excluded from the release ZIP.

## Important
Live government websites can change or block automated requests. This release does not falsely mark sources as live-verified. The run-all workflow reports per-source validation/fetch failures and continues with other sources.
