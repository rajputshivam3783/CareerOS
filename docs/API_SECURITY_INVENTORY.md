# API Security Inventory

Generated by `python backend/scripts/security_route_inventory.py --markdown` (an AST walk of
`backend/app/api/*.py`, so it needs no running app or database) and reviewed by hand for the
public routes below.

## How to read this â€” and what it does NOT prove

The **Auth class** column is derived from the dependencies *declared* on each handler
(`current_user`, `require_recruiter`, `guard`/`admin_guard`, `require_platform_permission`,
`require_permission_dual`, `require_organization_*`). It shows that a gate is present, not that
the gate is correct, and it cannot see checks performed inside a handler body (object
ownership, organization scoping, input validation, response filtering, rate limits, audit
rows). Those were reviewed by sampling in V25.6 (~15 object lookups in notifications, AI
conversations, Career Agent, skill-intelligence, applications, recruiter pipeline: all
enforce ownership and return 404 on mismatch) â€” **not exhaustively for all 476 routes.**
No dynamic IDOR / privilege-escalation test was executed (NOT VERIFIED).

| Class | Meaning | Count |
|---|---|---|
| ADMIN | platform administrator (named admin JWT, or the shared `X-Admin-Key` unless `ADMIN_KEY_AUTH_ENABLED=false`) or a platform permission | 152 |
| AUTHENTICATED | any signed-in user; object-level checks are inside the handler | 210 |
| RECRUITER | `require_recruiter`; data scope via `team_owner_ids` | 65 |
| ORG-SCOPED | `require_organization_membership` / role dependency | 15 |
| OPTIONAL-AUTH | works anonymously, personalises when signed in (search) | 4 |
| PUBLIC | no authentication dependency | 30 |

## Review of the 34 unauthenticated / optional-auth routes

| Route(s) | Why it is public | Review result |
|---|---|---|
| `POST /auth/register`, `/candidate/register`, `/recruiter/register` | account creation | rate limited; password policy; email verification required before login. Answers 409 for an existing email (account enumeration, accepted, F-26). |
| `POST /auth/verify-email`, `/resend-otp`, `/forgot-password`, `/reset-password` | pre-login recovery | rate limited per IP; OTP attempt cap; resend cooldown; **forgot-password per-account cooldown added in V25.6**; uniform responses. |
| `POST /auth/login`, `/candidate/login`, `/recruiter/login`, `/admin/login`, `/refresh` | authentication | per-IP limiter (admin login stricter), progressive lockout, uniform failure text, **timing equalised in V25.6**. |
| `POST /auth/password-strength` | UX helper | stateless; does not store or log the password. Verify the limiter covers it (NOT VERIFIED). |
| `GET /jobs`, `/jobs/{id}`, `/jobs/{id}/timeline`, `/jobs/{id}/exam-prep` | public job board | `get_public_job` returns 404 unless `status == "published"`. Response fields for `/jobs/{id}` were not individually reviewed (NOT VERIFIED). |
| `GET /government/*` (coverage, filters, search, home, sections, organizations, dashboard/extended) | public government-recruitment content | read-only catalogue data. |
| `GET /companies`, `/companies/{slug}` | public company pages | reviewed only at declaration level. |
| `GET /search`, `/search/autocomplete`, `/search/autocomplete/grouped`, `/search/facets`, `/search/semantic` | discovery | optional-auth; V21.x search-security audit documents permission filtering (`docs/SEARCH_SECURITY_AUDIT.md`); not re-executed. |
| `GET /ai/health` | liveness for the AI layer | **LOW / informational (F-25):** discloses configured provider names and uptime. Pinned as public by an existing test, so not changed. |
| `GET /notification-template-keys` | populate an admin dropdown | **INFORMATIONAL (F-25):** template key names only. Pinned as public by an existing test, so not changed. |

Outside `/api/v1` the application also serves `GET /health`, `/live`, `/ready` (public
probes) and `GET /metrics` (**V25.6: 403 in production unless `METRICS_TOKEN` is configured**).

## Guardrail

fails if the number of PUBLIC routes exceeds the reviewed ceiling (40), forcing a review note
here whenever an unauthenticated route is added. It has not been executed (see the audit
report).
